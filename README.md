# 家庭回忆录手机访谈工具

一个纯静态、可离线工作的安卓手机网页。老人资料和录音保存在当前手机浏览器的 IndexedDB 中；公开网站只放网页、通用问题和提问音频。

## 本地预览

在本目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。麦克风需要 HTTPS 或 localhost。GitHub Pages 部署后为 HTTPS，可直接用手机访问；添加桌面图标是可选的。

## 更新问题

编辑 `questions.json`，每个话题和问题使用稳定的英文 ID。不要把老人姓名、口述或录音写入此文件。

## 提问音频

先在设置页试听女声和男声样音，选定声音后，再在电脑上运行 `tools/generate-audio.ps1` 为欢迎语、补充提示和题库生成对应 MP3。脚本调用现有 `edge-tts`，生成时电脑要联网；老人手机缓存音频后可离线播放。脚本默认跳过已有音频，只有明确使用 `-Force` 才会覆盖生成音频。新增或改写问题后重新运行即可。试听样音放在 `audio/preview/`。

## 私人数据

会话、录音片段和设备设置存于浏览器 IndexedDB，不会上传到此静态站点。每日 ZIP 由浏览器本地生成。请收到并备份 ZIP 后，再在页面中手动清理手机录音。

请不要清除浏览器的网站数据或卸载桌面应用，除非当天录音已导出并备份。浏览器本地存储可能随这些操作一起被清除。
